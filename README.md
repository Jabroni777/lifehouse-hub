# Lifehouse Hub: installer downloads

The clinic hub for The Lifehouse check-in. It keeps patient names and visit history on one computer inside the clinic, encrypted with the clinic's passphrase.

**Download:** [LifehouseHub.pkg](https://github.com/Jabroni777/lifehouse-hub/releases/latest/download/LifehouseHub.pkg) (newest version, macOS 13 or newer, Apple silicon or Intel)

**Step-by-step setup, with pictures:** https://lifehouse-checkin-demo.netlify.app/install-guide

**How patient information is protected:** https://lifehouse-checkin-demo.netlify.app/white-paper

Each release lists the installer's SHA-256 checksum. This repository holds only the installers; the source code is kept privately.
